# Mingas Urbanas - Zona 2

Landing page de una sola página para Rover Scout Argentina.

## Ejecutar

Desde esta carpeta:

```powershell
npm.cmd install
npm.cmd run dev
```

Si PowerShell bloquea `npm`, usar `npm.cmd` como en los comandos anteriores.

La carpeta es independiente de `Proyecto_Bolsa_Laboral`.

## Contenido

- Hero con identidad visual Rover y navegación por las siete Mingas.
- Secciones para IEMA Flores, Virgen Inmaculada, San Pantaleón, CooPA, Cuenca en Red, La Poderosa y Piedrabuenarte.
- Cronograma de sábado y domingo.
- Botones de carga de fotos y videos preparados para enlazar Google Drive.
- Responsive para celular y escritorio, con animaciones de aparición al hacer scroll.
